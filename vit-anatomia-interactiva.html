Anatomía del Vision Transformer

Cada componente tiene un propósito específico; las tarjetas resumen su función dentro del ViT (Dosovitskiy et al., 2021).

🏷️

Token CLS

Token de clasificación (classification token)

Vector aprendible añadido al inicio de la secuencia. Recopila información global de todos los parches a través de las capas de atención.

💡 Al final, solo este token se usa para la clasificación.
🧩

Incrustación de parches

Imagen → secuencia (patch embeddings)

La imagen se divide en parches (p. ej., de 16×16 píxeles). Cada parche se aplana y proyecta a un vector de dimensión D (p. ej., 768).

📐 (224 / 16)² = 14 × 14 = 196 parches
📍

Codificación posicional

Información espacial (positional embeddings)

Vectores aprendibles que se suman a cada parche para preservar la información espacial. Sin ellos, el modelo no conoce la posición.

🎯 Esenciales para conservar la estructura 2D
🔗

Autoatención multicabeza

Comunicación global (multi-head self-attention)

Cada parche genera una consulta, una clave y un valor (Q, K, V). Varias «cabezas» aprenden diferentes tipos de relaciones en paralelo.

Attention(Q,K,V) = softmax(QK⊤/√dk)V
🔄

Conexiones residuales

Conexiones de salto (skip connections)

salida = x + Subcapa(LN(x)). Mitigan el desvanecimiento del gradiente y preservan información entre capas profundas.

🚀 Permiten apilar 12, 24 o 32 bloques (ViT-Base, ViT-Large y ViT-Huge)
📊

Normalización de capa (LayerNorm)

Estabilidad del entrenamiento

Normaliza las activaciones por muestra. Estabiliza el entrenamiento y acelera la convergencia.

⚡ En el ViT se aplica antes de cada subcapa (Pre-LN); el Transformer original la aplicaba después (Post-LN)

Bloque encoder del Vision Transformer

El bloque fundamental que se repite N veces en el Vision Transformer. En el ViT, la normalización de capa (LayerNorm) va antes de cada subcapa y la suma residual, después (pre-normalización o Pre-LN; Dosovitskiy et al., 2021, ecs. 2–3).

1. LayerNorm previa (Pre-LN)

LayerNorm: normaliza la entrada de cada subcapa, antes de la atención y antes del MLP.
Residual: salida = x + Subcapa(LN(x))

Las conexiones residuales mitigan el desvanecimiento del gradiente y permiten entrenar redes muy profundas. El Transformer original (Post-LN) normalizaba después de la suma; normalizar antes suele estabilizar el entrenamiento de redes profundas.

2. Autoatención multicabeza (multi-head self-attention)

Cada parche genera tres vectores: consulta (Q, query), clave (K, key) y valor (V, value).

Attention(Q,K,V) = softmax(QK⊤ / √dk) · V

Varias «cabezas» permiten aprender diferentes tipos de relaciones simultáneamente.

3. MLP (red feed-forward)

Dos capas lineales con activación GELU en medio:

MLP(x) = Linear(GELU(Linear(x)))
Dimensión: D → 4D → D

Procesa cada parche por separado con la información que reunió la atención.

💡 Concepto clave

Este bloque se repite N veces (12, 24 o 32 en ViT-Base, ViT-Large y ViT-Huge). Cada capa refina las representaciones, lo que permite que la información fluya y se combine de maneras cada vez más complejas.
